# Logos de tecnologías

Los SVG proceden de [Devicon](https://github.com/devicons/devicon), directorio
`icons/<tecnología>/<tecnología>-original.svg`. Se conserva su licencia MIT en
`DEVICON-LICENSE.txt`. Spring Boot se representa con el logo del ecosistema Spring.

El icono de Mockito procede de su [web oficial](https://site.mockito.org/favicon.ico).
Los nombres y marcas pertenecen a sus respectivos titulares.

Los archivos se sirven localmente; no hay dependencias de ejecución ni peticiones
a servicios externos para mostrar los logos.
